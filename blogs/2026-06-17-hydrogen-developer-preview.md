The next version of Hydrogen moves the commerce logic out of React Router into a framework-agnostic core. You can build storefronts in any JavaScript framework using Shopify's commerce primitives, and it ships with skills that coding agents use to scaffold a storefront for you. This is an early developer preview, and we're looking for your feedback as we keep building it out.
