Browser agents can now read and update Shopify checkouts using WebMCP tools for checkout . The tools let agents interact with the active checkout in the buyer’s browser session. When the buyer’s input is required, such as 3D Secure authentication or for blocking UI extensions, the tools hand back control to the buyer.
