Apps can now open Shopify’s native file picker with the Intents API. This lets your app prompt merchants to choose files from their Shopify file library without building a custom picker or sending them through a separate flow. With a single API call, your app can open the file picker, optionally filter by media type, enable multiple selection, and preselect files.
