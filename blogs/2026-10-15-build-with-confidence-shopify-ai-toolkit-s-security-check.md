Shopify AI Toolkit now includes shopify app security check , a security command that checks your app for common vulnerabilities before you ship. You can run it before you submit an app, and on every release, to find problems in your own code and get guidance to fix them. As AI accelerates how you build apps, attackers use the same tools to find and exploit security gaps faster and at lower cost.
